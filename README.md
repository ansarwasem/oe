# Ansar Wasem — One Page Website

A fast, modern, responsive landing page and portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## 🚀 Features
- **Ultra Fast**: Zero build steps, instant load time.
- **Responsive**: Perfectly optimized for mobiles, tablets, and desktops.
- **Modern UI**: Dark glassmorphic design, subtle glowing accents, and smooth scroll.
- **Ready for Vercel**: 1-click zero-config deployment.

## 📁 Project Structure
- `index.html`: Main semantic structure and sections
- `style.css`: Design styles, color system, and responsive breakpoints
- `script.js`: Mobile menu interactions, scroll listeners, and contact form handling
- `vercel.json`: Clean URL routing configuration for Vercel

## 🌐 Deploy to Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** -> **"Project"**.
4. Import your repository and click **Deploy**.
